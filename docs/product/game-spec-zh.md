# 遊戲規格（中文）

## 核心流程

1. 使用者登入（密碼或 SSO）。
2. 查詢今日剩餘抽獎次數。
3. 進行盲盒抽獎。
4. 系統回傳獎項並寫入歷史紀錄。

## 規則

- 每日抽獎上限由 `DAILY_DRAW_LIMIT` 控制。
- 成功抽獎會消耗一次配額。
- 已登入使用者可查看個人歷史紀錄。

## 角色

- `user`：可抽獎、查看個人紀錄。
- `super_admin`：可管理獎品與重置配額。

## 目前不包含

- 多租戶隔離。
- 多節點 websocket 水平擴展。
- 完整稽核匯出流程。
